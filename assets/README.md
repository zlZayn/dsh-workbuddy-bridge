## `7.png` 是历史件

`7.png` 拍的是 **0.1.5 时代的设置卡片**（`docs/archive/` 里那次双界面兼容的记录提到过它）。
本仓只支持 `0.1.7` 线，那份界面已不存在，所以门面**不再引用它**。

它留在目录里有两个原因：`docs/archive/` 的记录按名提到过它（记录不追改）；
删或改名的决定权在维护者。**判据**：确认不再需要对照旧界面后即可删除，删时同批更新本表。
