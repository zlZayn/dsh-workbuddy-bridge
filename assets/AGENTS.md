# assets/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

只讲**在这里要怎么干**；目录里有什么、被谁引用 → [README.md](README.md)。

## 什么时候必须重截

判据是「门面图里画出来的东西有没有变」，不是「改了哪个文件」。

必须重截：

- 插件页上的**标题、描述与图标** —— 本仓目前没有 `locale/` 与 `icon.svg`，插件页显示的是包名；
  补上那两样时，卡片相关的图都要重拍。
- 卡片与配置页的 **JSX 结构**：字段增删、顺序、标签页、按钮、状态行。
- 卡片可见状态的**语义**：目录来源（实时 / 已保存 / 内置）、账号状态、优惠徽章、模型显隐的勾选态。
- `src/client/*.module.css` 的**样式值**：字号、行高、间距、令牌、布局。
- **输入区那个推理等级控件的位置或外观**：它跟着宿主的槽走（见 [src/client/README.md](../src/client/README.md)），
  换槽或改样式都要重拍 `4.png`。
- 模型选择器里**分组名或模型名**的呈现方式。

不必重截：

- 类型与注释（只活在编译期）。
- 行为等价的内部重构：抽常量、改名、等价重写。
- `README` / `AGENTS` / 测试 / 构建配置。
- **模型列表内容本身**（上游上了新模型）：图里画的是分组与选择器形态，不是某一天的模型清单。

拿不准时按「必须重截」办：图的成本低于一张与界面不符的图。

## 完成定义

- 改渲染面的改动，**要么同批带重截图，要么在 commit body 里写明为什么不重截**。
- 图与文案分成两个提交，会留下「文案已改、门面里的图还是旧的」的窗口。

## 怎么拍

截图会改**全局设置**（界面语言等），所以第 0 步是问，不是动手。

0. **先问再动**，说清三件事再等维护者确认：要占用浏览器几分钟；会临时切界面语言、结束切回；
   **截图期间请别改语言 / 主题 / 模型等全局设置** —— 它们直接进画面。
1. **用自己的标签页**，不动维护者的标签页；结束关掉它。
2. **开一个新会话**再摆画面 —— 这一步是隐私要求：不新开会话，聊天区里就是正在进行的那段对话，
   连工具调用一起进图。摆好后不再动任何别的东西。
3. 按 [README.md](README.md) 的表走到对应画面；**拍摄前收起左侧栏**（展开的侧栏列的是维护者真实的
   会话标题与工作区名，门面图不能带出去）。收起是**带动画的**：点完要轮询到侧栏宽度连续两次采样相同
   再按快门，超时按报错重来 —— **不许拿中间帧凑数**。
4. **交还**：关掉自己的标签页，把语言切回去，告诉维护者可以用了。

## 已知约束

- **图里不许出现真实凭据**：卡片只允许出现账号与状态；`authFile` 那类只读行的输入框应当是空的。
- **整屏图不要设置 viewport**：用自然视口拍。改 viewport 会把 devicePixelRatio 压成 1，界面整体缩小。
- **文件名不许改**：两份门面按名引用；重拍后同名覆盖。
- 换图后跑一次链接校验（命令见根 [AGENTS.md](../AGENTS.md) 的「常用命令」）。
